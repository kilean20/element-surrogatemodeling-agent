# Keep local learning through ESA updates

A case can improve its methods offline while keeping its knowledge private.
User approval remains available; a recorded, revocable delegation can allow
validated local lessons or methods to become active without asking on each one.
Maintainer updates use a staged comparison and change-directed compatibility
review. They do not replace the case's fields, data, models or accepted knowledge.

Use the bundled [local-learning and update procedure](../skills/field-surrogate-workflow/references/local_learning_and_updates.md)
for MCP names, CLI commands, review requirements, revocation and recovery.
It is installed with the workflow skill, so global Genesis skills or this
source checkout are not required.

These are trusted-client consistency controls. Hashes do not prove the truth
of a lesson or semantic compatibility. Optional feedback sharing is a separate
decision; lack of a Drive connection does not disable local evolution.
