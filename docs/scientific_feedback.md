# Scientific feedback relative to installed ESA guidance

Collect useful accelerator-physics, numerical/modeling and workflow lessons,
then explicitly compare each important proposed improvement with the ESA release,
active client instructions and relevant KB/tool contracts actually used. Record
the baseline/version/hash, existing guidance, observation, precise difference,
classification, importance and proposed action locally. Do not infer novelty from
missing recall or an unsuccessful search. Covered-but-not-followed guidance is
useful failure evidence; a private machine fact is not automatically shared knowledge.

Keep the necessary generalized comparison in the existing feedback content fields.
Preserve detailed private context, project decisions and local customizations.
Content-only privacy checks and semantic review precede exact packet consent.
No automatic transcript/data attachments or shared-knowledge promotion occurs.

Google Drive is the selected destination. The maintainer can grant editor permission
to a user after an authorized request. This is separate from Google API authorization
and exact-content sharing consent. The proposed convenient helper reuses an allowed
write-capable connection or supports browser sign-in/folder selection and secure
credential refresh; it is not implemented by the current token-backed sender.
For an immediate lower-setup route, use the permitted Drive website: sign in,
obtain owner editor access and upload the reviewed small packet. An authorized
browser client can assist if supported. That web route needs no ESA API application.
The API helper is a separate automation option. Users should not handle tokens or
register their own OAuth application in that proposed flow. Application setup is maintainer work. A disabled connector must not
be bypassed; unavailable access leaves feedback local and modeling continues.

The bundled workflow references are installed_guidance_comparison.md,
scientific_feedback.md and google_drive_feedback_access.md. Both client setups
include them without global skills or developer memory. This procedure update does
not qualify LLM novelty/importance judgments, browser OAuth or actual live delivery.
