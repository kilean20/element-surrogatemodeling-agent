# Faithful card input and selected-artifact documentation

Use the pinned template headings in `model.sections`. Case, repeated whitespace
and trailing periods normalize to the same key; unknown keys and collisions
refuse before output. Read `model_section_coverage`. License text is controlled
by the particular artifact's explicit rights, so a supplied license narrative
does not override it. Do not treat this as silent input loss.

Native model cards include `selected_model_summary.json` and append its facts to
Model description. A fitted base can be trained on all rows before optimizer
step zero. An exactly zero neural output layer means no neural correction in
that selected function, even though network parameters still exist and full
inference timing includes the packaged implementation. Nonzero output weights
do not establish an accuracy advantage. Selection step and completed updates
alone establish neither neural convergence nor global model optimality. For
unsupported adapters, retain the uninspected status and supply accurate narrative
from the adapter's documented artifacts.

The bundled data-card schema has an optional software `version` slot restricted
to numeric releases. A faithful prerelease can instead appear in a local
identifier, for example `some-tool@3.1.0rc7`, with the optional numeric slot
absent. The generator uses its exact installed version for its own software
creator entry when none is supplied. It does not assert that a stable version
exists. Supplied records remain unchanged; preflight reports incompatible
versions and suggests an explicit representation. Read the raw pinned validator
receipt after rendering to confirm actual conformance.

Keep missing contact, original authors, sponsor/research organization, sensitivity
and publisher facts separate from software/schema issues. Ask for the applicable
user facts, or preserve unknowns and a draft. The agent's software license and
maintainer do not supply ownership or reuse terms for user-generated artifacts.
